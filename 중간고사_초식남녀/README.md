- 이미지 생성: ChatGPT / 영상화: Runway / 내레이션: 네이버 클로바더빙
- 모션 그래픽 제작, AI 영화 최종 편집: Python(Pillow, NumPy, SciPy), ffmpeg
- 기획·코드·편집 보조: Claude (Anthropic)
